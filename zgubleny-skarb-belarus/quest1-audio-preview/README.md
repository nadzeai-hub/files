## Фактическая проверка

В облачном настольном Chromium пройдены обе ветки до финала. Проверены пустой ответ; неверный и верный порядок записки; неверное объяснение; неверная пятёрка находок и исправление; помещение/возврат/исключение карточки; куфэрак; неверные пары и объяснения; оба орнамента и подсказки; неверный символ тайника; финал без поля ввода; обновление страницы с сохранением; смена ветки; повторное прохождение. В старшей ветке сохранённые общие находки второй сцены используются согласно исходной механике.

Воспроизведение, повтор, остановка, отсутствие наложения, прекращение звука при выборе и при открытии куфэрка проверены по реальному состоянию HTMLAudioElement. Отказ play() искусственно смоделирован через qa-layout.html: сообщение об ошибке появляется, куфэрак после этого открывается. Реальное отключение сети/404 и закрытие вкладки отдельно не воспроизводились.

Размеры 375, 430, 768, 1366 CSS px проверяются в iframe через qa-layout.html. На этих размерах ширина документа совпала с viewport, горизонтального переполнения нет. Это проверка компоновки в настольном браузере, не тест реальных iPhone/Android/iPad/Safari. Полная будущая озвучка всех сцен пока не проверена, поскольку её записей нет.
