# Копия с компактными сценами

Основа: quest1-vasilka-voice, индекс 2125fd6e67fd68afddb591e107e41e0c96e8dc07.

Содержание, ответы, иллюстрации и все исходные игровые обработчики сохранены. Изменены только CSS, визуальные контейнеры и отдельные ключи прогресса zgubleny-skarb-q1-fit-*.

Сцены ограничены высотой доступного экрана. Кнопки первой сцены и проверки архива закреплены в нижней части; описание находки и объяснение связи в старшей ветке открываются в диалоге. На узком экране маршрут сворачивается в кнопку карты. Длинная активная область может прокручиваться внутри сцены: текст не уменьшается до нечитаемого размера.

Голос остаётся принятым вариантом +4 полутона; новые пробы не заменяют записи в игре. MP3 и лицензии сохранены.

Проверка браузером — в процессе.
